# Хоббика × Богачо

Публичное предложение о сотрудничестве, версия 7 октября 2026 года.

Создано на основе установленного `hobbyka-brand-web` 0.3.1: оригинальный логотип, Inter, тема и компоненты Хоббики. Исходники компонентов сохранены в `src/components/hobbyka` для правки дизайнером и разработчиком. Материалы предложения находятся в `src/main.tsx` и `src/data.ts`; изображения и документы — в `public`.

Локальный запуск: `npm ci`, `npm run dev`.
Проверка: `npx tsc --noEmit`, `npm run build`.
Публикация: GitHub Pages через `.github/workflows/publish.yml`, каталог `dist`.

Изображения являются концептуальными визуализациями, коммерческие условия — предложениями для согласования.
